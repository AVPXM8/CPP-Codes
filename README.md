# C++ Data Structures & Algorithms (DSA)

This repository serves as a comprehensive collection of Data Structures and Algorithms implementations in C++, along with optimized solutions for various LeetCode problems. 

Designed for clarity and efficiency, these implementations cover fundamental to advanced topics, providing a solid foundation for competitive programming and technical interviews.

---

## Project Structure

| Category | Description |
| :--- | :--- |
| **[Array](./Array)** | Solutions for array manipulations, including Two Sum and Sort Colors. |
| **[Basic](./Basic)** | Introductory C++ concepts and fundamental logic building. |
| **[Bitmanupulation](./Bitmanupulation)** | Advanced bitwise operation techniques and tricks. |
| **[LinkedList](./LinkedList)** | Implementations of Singly and Doubly Linked Lists with cycle detection. |
| **[OOPS](./OOPS)** | Object-Oriented Programming principles including Encapsulation and Classes. |
| **[PrefixSum](./prefixSum)** | Efficient range query problems using the Prefix Sum technique. |
| **[Recursion](./Recursion)** | Solutions for subsets, subsequences, and recursive backtracking. |
| **[Stack](./Stack)** | Stack data structure applications and custom implementations. |
| **[String](./String)** | String parsing, manipulation, and pattern matching problems. |

---

## Highlights

- **Optimized Algorithms**: Implementations focused on best-case time and space complexity.
- **Modern C++**: Utilizing C++11 and beyond (`nullptr`, `vector`, `auto`).
- **Encapsulation**: Clean OOPS design in class-based implementations.
- **Memory Safety**: Focused on preventing leaks through proper cleanup logic.

---

## How to Run

To compile and execute any solution locally, ensure you have a C++ compiler (like `g++`) installed.

1. **Compile**:
   ```bash
   g++ -o solution filename.cpp
   ```

2. **Run**:
   ```bash
   ./solution
   ```
